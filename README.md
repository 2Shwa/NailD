# 💅 Nail:D

3D 기반 네일 디자인 및 커스텀 네일 시뮬레이션 서비스

사용자가 3D 손톱 위에 네일 디자인을 미리 적용해보고,
직접 꾸미며 자신만의 네일을 제작할 수 있는 웹 서비스입니다.

Figma를 활용해 UI를 설계하고 React를 기반으로 프론트엔드를 구현하고 있으며, 향후 3D 기능을 추가하여 실제 서비스로 발전시키는 것을 목표로 하고 있습니다.

---

## 구현 기능

- Figma 기반 UI/UX 설계
- React 기반 화면 구현
- 반응형 UI 적용

---

## 🚧 개발 예정 기능

- React Three Fiber를 활용한 3D 네일 디자인
- 네일 컬러 및 파츠 커스터마이징
- 디자인 저장 및 불러오기
- 즐겨찾기 기능
- 디자인 공유 게시판
- 회원 기능

## 프로젝트 목표

Nail:D는 사용자가 원하는 네일 디자인을 직접 제작하고, 완성된 모습을 3D 환경에서 미리 확인할 수 있도록 기획한 웹 서비스입니다.

단순히 네일을 꾸미는 기능에 그치지 않고, 완성한 디자인을 저장하거나 공유하여 다른 사용자와 아이디어를 나눌 수 있는 플랫폼을 목표로 하고 있습니다. 
또한 원하는 디자인을 네일샵 방문 시 참고 자료로 활용하거나 셀프 네일에도 사용할 수 있는 실용적인 서비스를 만드는 것을 목표로 개발하고 있습니다.
